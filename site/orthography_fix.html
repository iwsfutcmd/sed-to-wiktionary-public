Open next page or next at once
  1. Press Open next page (or N) for one tab, or Open next … at once to open several tabs in a row. Each opens as an edit form with the fix already made and the diff showing.
  2. In each tab, check the highlighted changes, then press Save changes on Wiktionary — in any order, whenever you get to it. If something looks wrong, close the tab instead; nothing was saved.
  3. The tab closes itself once the save goes through. Coming back to this tab, you'll be asked once whether everything still "open" actually saved — say yes and the whole batch is ticked off in one click. (A lone page can still be marked with its own Done/Skip in the table below.) Repeat.

One-time setup: install the script on your Wiktionary account
  1. Open your common.js (it may be empty or new).
  2. Paste everything below at the end of it and save. Then reload with Ctrl+Shift+R.
  3. The script does nothing on any other edit. It only acts on edit links from this page, which end in &respell=1.

It needs the plain edit box. If you use CodeMirror syntax highlighting, switch it off for these edits.

    Root or verb? ()

    These pages cite a hyphenated root such as ṯ-ḳ-l where the bare verb page (ṯḳl) exists. A bare page is the verb, a hyphenated page is the abstract root (data/wiktionary/root_vs_verb.md). “Guess” reads the line: a root-style gloss (“related to …”) is the root and needs nothing; a plain word gloss is the verb; “check” mentions a root in the line, so read it. To verb opens the edit form with only that one reference pointed at the bare page (it needs the script above).
