Respell Proto-Semitic references

151 pages link to a spelling that WT:ASEM does not use. Each one opens in the edit form with the fix already made and the diff showing. You read it and press Save.

Open next page
  1. Press Open next page (or N). The page opens in a new tab as an edit form, the fixed text is in the box and “Show changes” has been pressed for you.
  2. Check the highlighted changes, then press Save changes on Wiktionary. If something looks wrong, close the tab; nothing was saved.
  3. Come back here and press Open next page again. That also ticks off the page you just did.
One-time setup: install the script on your Wiktionary account
  1. Open your common.js (it may be empty or new).
  2. Paste everything below at the end of it and save. Then reload with Ctrl+Shift+R.
  3. The script does nothing on any other edit. It only acts on edit links from this page, which end in &respell=1.

It needs the plain edit box. If you use CodeMirror syntax highlighting, switch it off for these edits.
